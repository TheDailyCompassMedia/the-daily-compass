THE DAILY COMPASS — WEBSITE STARTER
====================================

This is a simple, mobile-friendly static website starter for The Daily Compass.

FILES
- index.html: homepage and the three topic sections
- styles.css: layout, colors, and responsive styling
- script.js: small mobile navigation behavior and copyright year
- compass.svg: site icon
- robots.txt: basic search-engine crawler instructions

PUBLISHING WITH CLOUDFLARE PAGES — DIRECT UPLOAD
1. In Cloudflare, open Workers & Pages.
2. Choose Create application.
3. Choose the Pages / upload-assets / drag-and-drop route (wording can vary).
4. Give the project a name such as the-daily-compass.
5. Upload this ZIP file and deploy.

IMPORTANT
- Upload the ZIP itself or its extracted folder using the dashboard's drag-and-drop upload flow.
- Do not use the Worker command "npx wrangler deploy" for this static website.
- This is a Direct Upload site. Cloudflare says a Direct Upload project cannot later be converted into a Git-integrated project. Future edits can be uploaded as a new deployment; automatic GitHub deployments would require creating a separate Git-integrated project.
- The three topic areas currently say "Guides coming soon". Replace those with researched articles before presenting the site as a full publication.
- This is a static website: it does not include a working newsletter signup, comments, login, or contact form.
- A free pages.dev address is provided by Cloudflare. A custom .com domain normally costs money.
